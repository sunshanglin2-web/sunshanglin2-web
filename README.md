## 🎯 我在做什么

**嗒嗒日记(TATTA JOURNAL)** —— 一个以**个人成长与自我探索**为核心的品牌。

帮助一个人看见自己,理解自己,并逐渐发现自身尚未被认识的可能性。

- **立意**:向内觉察,自我成长
- **哲学**:**无形托举着有形** —— 品牌的关键在内容,不在货
- **风格**:中国苏式园林哲学(虚实、借景)+ 极简主义,三者碰撞融合
- **主线**:时间——天象时序、自然材质沉淀、日复一日的自我记录

> ⚠️ **重要定位**:Tatta Journal **不是一个以占星为核心的品牌**。占星可以成为未来辅助自我探索的工具之一,但它不是品牌的主要身份,也不应该成为用户理解品牌的门槛。
