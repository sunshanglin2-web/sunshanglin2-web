# 🎨 设计稿归档

本目录用于归档「嗒嗒日记 TATTA JOURNAL」品牌的设计稿、方案与版本。

> 设计文件(psd / ai / fig / eps / svg / png 等)请通过 GitHub 上传到对应目录。

---

## 目录约定

| 目录 | 内容 |
|------|------|
| `00-brand/` | 品牌定位、策略、关键词板 |
| `01-identity/` | 视觉识别系统:Logo、色彩、版式、辅助图形 |
| `02-fonts/` | Tatta Journal 字体系 |
| `03-products/` | 产品线设计:星象日记本、首饰等 |
| `04-web/` | 官网与线上阵地设计稿 |
| `versions/` | 各阶段版本归档(按日期) |

---

## 命名约定

- 文件命名:`YYYYMMDD_名称_版本`(示例:`20261119_logo_v2.svg`)
- 版本:V1、V2… 或 `alpha` / `beta` / `final`
- 大版本更新时,把旧版移入 `versions/`
- 每个阶段目录放一份 `README.md`,记录该阶段的关键决策

---

## 结构示例

```text
design/
├── 00-brand/        # 品牌定位、策略
├── 01-identity/     # Logo、色彩、版式
├── 02-fonts/        # Tatta Journal 字体系
├── 03-products/     # 产品线(星象日记本、首饰)
├── 04-web/          # 官网设计稿
└── versions/        # 历史版本归档
```
